# 소환수 전투 고도화 기획서 (MVP 후보군)

## 1. 소환수 전투 전략성 강화 (자동 사냥 방지)

이 게임은 소환수를 주로 활용하지만, 단순히 소환 후 방치하는 것은 지루함을 유발할 수 있습니다. 플레이어의 개입을 유도하기 위한 전략적 요소 후보입니다.

*   **타겟 마킹 (Target Marking)**
    *   **개념**: 플레이어가 직접 공격하거나 특정 스킬을 맞춘 적에게 '마킹'을 부여.
    *   **효과**: 모든 소환수가 마킹된 대상을 최우선으로 일점사함.
    *   **장점**: 조작이 단순하며 플레이어의 공격 행동에 전략적 의미를 부여.

*   **명령 토글 (태세 전환 / Stance)**
    *   **개념**: 단일 단축키를 통해 소환수들의 전체 상태를 변경.
    *   **효과**:
        *   `공격 태세`: 사거리 내 적을 자유롭게 탐색 및 공격.
        *   `호위 태세`: 플레이어 주변으로 복귀하여 다가오는 적만 방어.
    *   **장점**: 위급 상황 시 소환수를 방패로 사용하거나 적진으로 파고드는 전술 가능.

*   **명령 투척 / 강제 이동 (Positioning)**
    *   **개념**: 특정 지점에 표식(플레어 등)을 던져 소환수 강제 이동.
    *   **효과**: 이동 경로의 적에게 피해를 주며, 도착 지점을 일정 시간 방어.
    *   **장점**: 길목 차단 및 적 진형 붕괴 등 공간적 전술 활용 가능.

*   **공명 / 기폭 (Synergy / Detonation)**
    *   **개념**: 소환수의 공격과 플레이어의 스킬 연계.
    *   **효과**:
        *   소환수가 적 타격 시 스택 누적 -> 플레이어 전용 스킬로 폭발 피해.
        *   또는 소환수 자체를 폭발(희생)시켜 강력한 광역 피해 발생 (재소환 페널티).
    *   **장점**: 소환수와 플레이어 간의 능동적인 콤보 액션 제공.

## 2. 몬스터 패턴 및 소환수 생존 기믹 (소울류 회피 메리트)

적 몬스터의 광역기(장판 등)에 소환수가 무력하게 쓸려나가 소환사의 메리트가 사라지는 문제를 방지하기 위한 기믹 후보입니다.

*   **소환수 회피 동기화 (Dodge Sync)**
    *   **개념**: 플레이어가 회피(구르기/대시) 타이밍을 맞출 경우.
    *   **효과**: 플레이어의 회피 시간 동안 소환수에게도 동일하게 무적(혹은 판정 제거) 부여.
    *   **장점**: '피하는 재미'를 극대화하며 플레이어의 컨트롤 역량이 소환수 생존으로 직결.

*   **즉각적인 소환수 회수 (Recall / Hide)**
    *   **개념**: 특정 키 입력 시 소환수들을 즉시 무적 구역(플레이어 그림자 등)으로 회수.
    *   **효과**: 적의 강력한 광역기 캐스팅 시 빠르게 소환수를 대피시키고 패턴 종료 후 재전개.
    *   **장점**: 캐스팅 패턴에 대한 직관적인 대처법 제공.

*   **광역기 피격 데미지 보정 (AoE Resistance)**
    *   **개념**: MMORPG의 펫 시스템 차용.
    *   **효과**: 소환수는 적의 광역 공격에 대해 피해를 크게 감소(예: 80%~90%)하여 받음. 대신 소환수 전용 단일 타겟팅 패턴 추가.
    *   **장점**: 광역기 스트레스 완화, 소환수 체력 관리라는 다른 측면의 재미 부여.

*   **죽음의 자원화 (Sacrifice / Counter)**
    *   **개념**: 소환수의 죽음을 페널티가 아닌 플레이어의 버프로 활용.
    *   **효과**: 광역기에 소환수가 사망 시 폭발하여 적에게 피해를 주거나 플레이어에게 강화 버프 제공.
    *   **장점**: 적의 강력한 패턴을 오히려 딜타임이나 버프 획득의 기회로 역이용 가능.

*   **패턴 방패막이 (Bodyblocking)**
    *   **개념**: 플레이어를 집요하게 노리는 특정 패턴에 대한 파훼법.
    *   **효과**: 유도 투사체나 돌진기를 소환수 뒤에 숨어서 소환수가 대신 맞도록 유도.
    *   **장점**: 소환사 클래스만의 고유한 패턴 파훼 재미 제공.
